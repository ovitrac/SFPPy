📋 Workflow Overview

Follow these steps to run a migration simulation

1

🧪 Substances Tab

Define the migrants (additives, monomers, contaminants) to simulate. Search PubChem for substances or select from common additives like Irganox 1076, BHT, DEHA. Each substance needs a CAS number for accurate property lookup.

Key features: PubChem integration, regulatory SML values (EU/US/CN), Cramer classification
2

🧱 Assembly Tab

Build your packaging structure: monolayer or multilayer (up to 10 layers). Select polymers (LDPE, PP, PET, etc.), set layer thicknesses, and define initial concentrations (C₀) for each substance in each layer. Choose packaging geometry (box, cylinder, bottle) for accurate surface-to-volume calculations.

Key features: Layer visualization, C₀ matrix, geometry selection, auto-computed diffusivities (Piringer model)
3

🍽️ Food Tab

Define the food/simulant contact conditions. Select food category (aqueous, fatty, alcoholic) and simulant (water, ethanol 10-95%, olive oil, etc.). Configure contact steps: temperature, duration, and contact mode.

Key features: Multi-step scenarios, 📦 set-off mode (stacking/rolling before food contact), EU simulant compliance
4

▶️ Simulate Tab

Review your configuration summary and run the simulation. The Patankar finite-volume solver computes migration kinetics for all substances through the multilayer structure. Load example sessions or presets for quick testing.

Key features: Validation check, restart from previous simulation, session management
5

📊 Results Tab

Visualize migration kinetics (CF vs time), concentration profiles (C vs position), and compliance status. Compare final concentrations against SML values. Export results as PDF reports, CSV data, or interactive plots.

Key features: Interactive charts, SML compliance badges, multi-substance comparison, PDF/CSV export

🔬 ToxTree & NIAS Assessment

Toxicological evaluation for Non-Intentionally Added Substances

Cramer Classification (ToxTree)

The Cramer decision tree classifies substances into three classes based on chemical structure and predicted toxicity:

Class I Low concern — TTC: 30 µg/kg bw/day → 1.8 mg/kg food
Class II Intermediate — TTC: 9 µg/kg bw/day → 0.54 mg/kg food
Class III High concern — TTC: 1.5 µg/kg bw/day → 0.09 mg/kg food
☢️ Genotoxic TTC: 0.0025 µg/kg bw/day → 0.00015 mg/kg food

* Max Exposure assumes 60 kg adult, 1 kg food/day consumption (EU convention).

Structural Alerts

ToxTree identifies structural alerts. Genotoxic alerts require the strictest threshold:

☢️
Genotoxic Alert

Detected keywords: genotox, mutagen, carcinogen, DNA.
TTC = 0.0025 µg/kg bw/day applies — individual risk assessment mandatory.

⚠️
Informational Alert

Other structural alerts (skin sensitization, eye irritation, etc.).
Relevant for cosmetics/homecare applications. Cramer TTC still applies for food.

✓
No Alerts

No structural alerts identified. TTC approach can be used for initial safety assessment.

NIAS Assessment

NIAS (Non-Intentionally Added Substances) have no regulatory SML. Use the TTC-based limit as a screening threshold. If simulated migration exceeds the TTC limit, a full toxicological evaluation is required. Always check for structural alerts.

🔬 Technical Details

Solver

Patankar finite-volume method with adaptive meshing. Handles discontinuous diffusion coefficients at layer interfaces.

Diffusivity Models

Piringer (EU default), Welle FHP, or user-defined values. Temperature-dependent via Arrhenius activation energy.

Chemical Database

PubChem integration via migrantToxtree. Cached data for EU/US/CN regulated substances.

Regulatory Compliance

SML values from EU 10/2011, US FDA 21 CFR, CN GB 9685. Cramer classification for TTC assessment.
