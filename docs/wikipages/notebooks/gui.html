Synopsis

  • SFPPy-GUI 💫 offers an intuitive, code-free interface for evaluating the safety of food contact materials through advanced mass transfer and migration modeling. This interactive notebook leverages the core SFPPy library, providing the same robust features and capabilities (e.g. simulation chaining, databases, plotting, exporting...) while ensuring ease of use.
  • Results are stored in global dictionaries, enabling seamless integration of various conditions, materials, and substances for flexible analysis. The framework is designed for easy extensibility, allowing users to customize and expand functionalities as needed.
  • Built for versatility, the SFPPy ecosystem operates effortlessly in both secure, cloud-based environments (e.g., Google Colab) and local installations, ensuring adaptability to different workflows and privacy requirements.

🛠️ How to Use SFPPy-GUI¶

  1. 🚀 Initialize the Notebook: Run all cells and ensure no errors appear in the Global Setup.
  2. 🍽️ Set Contact Conditions: Define the food type (🥗🍓🍞🍰🥩), process (🔥♨️🍳), or storage condition (☀️❄️⏱️).
    • Click "Instantiate Custom Condition".
  3. 📦 Define Packaging: Choose a packaging shape (🥫🍼🫙🍱🛍️) and instantiate layers (up to 10).
    • Click "Create Packaging" and "Instantiate all layers".
  4. 🧪 Select a Migrant: Search for a substance (⌬) among millions in the database, then instantiate it for simulation.
  5. 📊 Run the Simulation: Refresh the Simulation Widget (CTRL+Enter), modify settings if needed, and press "Launch Simulation".
  6. 📉 Analyze the Results: Refresh the Result Widget (CTRL+Enter) and choose from:
    • 📈 Plot concentration kinetics (time evolution of substance migration).
    • 🏗 Plot concentration profile (distribution within layers).
    • 🎯 Evaluate a specific condition.
    • 📋 Generate a table of values.

5 | Launch simulation 🚀⋆✴︎˚｡⋆¶

SFPPy integrate pipelines to evaluate complex operations. Three operators are used % (substance ⌬ injection), << (inherit) and >> (propagate, run). The pipeline prototype is:

m% F << G >> P >> S >> S
substance food or contact condition geometry/shape material (multilayer) simulation result

7 | How to develop more complex food contact 🍽️ scenarios: an overview¶

Running a simulation with $n$ steps F1…Fn is coded from left to right reads as:

m % F ⏪ G⏩ P ⏩ F1 ⏩ F2 …⏩ Fn
Click to expand details on operators and pipelines.

A pipeline invokes operators (%,<< and >>) to stream information and mass transfer in complex scenarios.

action injection of substance m inherit geometry G propagate or run
operator % << >>
syntax m % F ➡ F
m % P ➡ P
F ⬅ F << G F >> P ➡ P
P >> F ➡ S
S >> F ➡ S

The direction of the operator is indicated by ⬅ or ➡, and the operands are:

m F G P S
substance food or contact condition geometry/shape material (multilayer) simulation result
