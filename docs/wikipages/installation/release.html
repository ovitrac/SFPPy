                About SFPPy

                SFPPy is a Python-based framework for 𓌉◯𓇋 compliance testing of food contact materials and 🎢⌬♻️ recycled plastic safety assessment. It supports regulations from:

                • 🇺🇸 US FDA regulations

                • 🇪🇺 European Union (EFSA, EU 10/2011, etc.)

                • 🇨🇳 Chinese GB standards

                • 🌍 Other international guidelines

                📌 SFPPy integrates well-established chemical migration models into Python, offering object-oriented and scalable capabilities. It includes a comprehensive collection of scenarios 🗃 for various applications.

                🔔 Starting from version 1.3, the computational engine ⚙️ automatically selects the best model 🤔 to predict 🪄 diffusivities and partitioning from molecular structures ⌬.

                🚀 No Python Knowledge? No Problem! 🧑‍🔬👩‍🔬 SFPPy is designed for scientists, engineers, and food packaging experts without programming experience. You can simulate mass transfer or analyze results using 🔹 simple commands and 🔹 pre-built functions that handle complex calculations internally.

                📦 Download & Installation

                SFPPy is available in two versions 🗜️ ┊ Compatible with 🪟 Windows, 🐧 Linux, 🍎 macOS.

                The light version does not include the private installation of Toxtree, which is used in patankar.loadpubchem.migrantToxtree for advanced risk assessment. However, patankar.loadpubchem.migrant remains fully functional for routine simulations.

                If needed, Toxtree can be manually installed in patankar/private/toxtree/ as described in patankar/private/toxtree/README.md.
